# Don't Forget Me: store assets

Graphics for the Google Play listing, matching PR #1 (the redesign).

| File | Play Console field | Size |
|---|---|---|
| `icon-512.png` | App icon | 512×512 |
| `feature-graphic-en.png`, `feature-graphic-he.png` | Feature graphic | 1024×500 |
| `screenshots/screenshot-en-1..6.png` | Phone screenshots (English listing) | 1080×1920 |
| `screenshots/screenshot-he-1..6.png` | Phone screenshots (Hebrew listing) | 1080×1920 |
| `logo.svg`, `icon.svg`, `logo-transparent.png` | Vector logo and icon, for any other use | |
| `before-after.png` | Old vs. new design (for review, not for the store) | |

The icon, logo and feature graphics are generated by `scripts/brand/generate.mjs` in the app repo.
